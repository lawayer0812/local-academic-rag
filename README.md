# 📚 Local Academic RAG

一个面向学术研究的本地文献检索与证据定位工具。

你可以上传自己的 PDF 论文建立本地知识库，然后输入一个学术观点，系统会帮助你快速定位：

- 相关论文
- PDF 页码
- 原文证据
- DeepSeek 整理后的证据说明
- 原文中涉及的参考文献
- 完整参考文献条目（能够匹配时）

系统使用 **BGE-M3 + ChromaDB + DeepSeek**，PDF 与向量数据库默认保存在自己的电脑中。

---

## 💡 可以用它做什么？

例如，你想确认下面的观点是否在自己的文献中出现过：

> 城市经历可能改变个体进行社会比较时采用的参照标准。

系统会在你上传的论文中进行语义检索，并帮助你找到最相关的论文、PDF 页码和原文证据。

特别适合：

- 文献综述
- 查找某个观点的出处
- 核对论文中的理论论述
- 寻找可以支持某一论断的文献
- 快速定位长篇 PDF 中的相关段落
- 追溯正文引用的参考文献

# 🚀 Mac 安装方法

## 1. 下载项目

在 GitHub 项目页面点击：

**Code → Download ZIP**

下载完成后解压到任意位置，例如桌面。

---

## 2. 检查 Python

本项目需要 Python 3。

打开 Mac 的“终端”，输入：

```bash
python3 --version
```

如果出现类似：

```text
Python 3.12.0
```

说明已经安装 Python。

如果提示找不到 Python，请先安装 Python 3。

---

## 3. 一键安装

进入下载并解压后的项目文件夹，双击：

```text
install_mac.command
```

安装程序会自动：

1. 创建独立的 Python 虚拟环境
2. 安装项目需要的 Python 软件包
3. 创建论文文件夹
4. 创建本地向量数据库文件夹
5. 创建 DeepSeek 配置文件

第一次安装需要下载相关依赖，可能需要几分钟。

BGE-M3 模型也需要在首次使用时下载，因此第一次运行需要保持网络连接。

---

# 🔑 配置 DeepSeek API Key

本项目使用 DeepSeek API 对检索到的学术证据进行整理。

安装完成后，在项目文件夹中找到：

```text
.env
```

打开后可以看到：

```text
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

将：

```text
your_deepseek_api_key_here
```

替换成自己的 DeepSeek API Key。

例如：

```text
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

保存文件即可。

> ⚠️ 请不要把自己的 `.env` 文件或 DeepSeek API Key 上传到 GitHub，也不要发送给其他人。

---

# ▶️ 启动学术文献助手

安装并配置 API Key 后，双击：

```text
启动学术文献助手.command
```

程序启动后，在浏览器中打开本地网页即可使用。

---

# 📥 添加自己的论文

进入网页后，打开：

**📥 添加新论文到知识库**

选择需要加入知识库的 PDF，然后点击：

**➕ 加入知识库**

系统会自动完成：

```text
PDF
 ↓
提取文本
 ↓
按页切分文本
 ↓
BGE-M3 生成文本向量
 ↓
写入 ChromaDB
 ↓
进入自己的本地知识库
```

处理完成后即可检索。

以后添加新的 PDF 时，不需要重新处理已经进入知识库的旧论文。

---

# 🔍 检索学术观点

系统目前支持两种检索方式。

## 全库检索

在自己已经建立的全部论文知识库中检索。

例如：

> 教育扩张是否会改变相对教育位置的作用？

适合寻找：

- 哪篇论文讨论过这个观点？
- 哪些文献可以支持这个论述？
- 我的文献库里有没有相关研究？

## 指定文献检索

只在指定的一篇论文中进行检索。

例如：

> 这篇论文是否讨论了学校阶层分割？

适合已经知道目标论文，只希望快速找到具体位置的情况。

---

# 📖 查看原文证据

检索完成后，系统首先显示 BGE-M3 找到的主要相关位置，包括：

- 论文名称
- PDF 页码
- 文本相似度

点击：

**📖 打开原文第 X 页**

即可在浏览器中打开原始 PDF，并跳转到相应页码附近进行人工核对。

---

# 🤖 学术证据整理

完成语义检索后，DeepSeek 会进一步结合检索文本和相邻文本整理证据。

主要包括：

- 定位结论
- 最相关证据
- 原文内容
- 涉及的参考文献
- 使用建议

系统要求 DeepSeek 尽量只依据知识库实际检索到的内容进行整理，而不是自行补充不存在的文献证据。

---

# 🔗 参考文献追溯

如果相关原文中明确出现类似：

```text
(Wang, 2017)
```

或：

```text
(Knight & Gunatilaka, 2010b; Wang, 2017)
```

系统会尝试识别这些作者—年份引用，并从该论文的参考文献部分寻找对应的完整参考文献条目。

如果能够成功匹配，会在证据整理结果中显示相关参考文献。

如果无法可靠匹配，则不会自行虚构完整文献信息。

# 🔒 数据与隐私

本项目采用本地知识库。

以下内容默认不会上传到本项目的 GitHub 仓库：

```text
.env
.venv/
papers/
chroma_db/
```

因此：

- DeepSeek API Key 保存在自己的电脑上
- 原始 PDF 保存在自己的电脑上
- ChromaDB 向量数据库保存在自己的电脑上

需要注意：使用 DeepSeek 进行证据整理时，相关检索文本需要发送给 DeepSeek API 进行处理。

# 🧰 主要技术

本项目目前使用：

- Python
- Streamlit
- PyMuPDF
- BGE-M3
- Sentence Transformers
- ChromaDB
- DeepSeek API

基本工作流程：

```text
PDF 文献
   ↓
PyMuPDF 文本提取
   ↓
按 PDF 页面切分文本
   ↓
BGE-M3 向量化
   ↓
ChromaDB 本地知识库
   ↓
语义检索
   ↓
补充相邻文本
   ↓
DeepSeek 整理学术证据
   ↓
原文页码 + 参考文献定位
```

# ❓ 常见问题

## 第一次运行为什么比较慢？

第一次使用时需要下载 BGE-M3 模型，并初始化相关 Python 依赖，因此速度会比之后慢。

---

## DeepSeek 调用失败怎么办？

首先检查项目中的 `.env` 文件是否已经正确填写：

```text
DEEPSEEK_API_KEY=你的APIKey
```

同时确认 DeepSeek API Key 可以正常使用。

---

## PDF 点击后打不开怎么办？

关闭程序后重新双击：

```text
启动学术文献助手.command
```

再尝试打开 PDF。

---

## 新上传的论文为什么暂时搜索不到？

确认网页已经提示论文成功加入知识库，然后刷新知识库或重新启动程序。

---

## 可以上传中文论文吗？

可以。中文和英文论文都可以加入知识库。

# ⚠️ 学术使用提醒

本工具的主要目标是**帮助研究者快速定位证据，而不是替代研究者进行最终的文献核验**。

大语言模型整理结果可能存在遗漏或错误。

因此，在正式论文写作、引用和投稿之前，请务必：

1. 点击原始 PDF；
2. 核对原文；
3. 核对实际 PDF 页码；
4. 核对作者、年份和完整参考文献；
5. 确认原文确实能够支持自己的论述。

建议把本工具理解为：

> **“帮我快速找到可能在哪里”，而不是“替我完成最终学术核验”。**
