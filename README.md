# 📚 本地学术文献助手 Local Academic RAG

一个面向学术研究的本地文献检索与证据定位工具。

你可以将自己的 PDF 论文导入本地知识库，然后直接输入一个学术观点、关键词或研究问题。系统会从论文中检索相关内容，并结合 DeepSeek 帮助你快速定位：

- 📄 相关论文
- 📍 PDF 页码
- 📝 原文证据
- 🔗 相关参考文献
- 📚 可继续追溯的文献线索

适合文献阅读、论文写作、文献综述和观点出处核查等场景。

---

## 一、主要功能

### 1. 本地 PDF 文献库

将 PDF 论文上传到系统后，程序会自动：

1. 提取 PDF 文本；
2. 按页切分文本；
3. 使用 BGE-M3 生成向量；
4. 保存到本地 ChromaDB；
5. 建立可检索的个人学术文献库。

PDF 文件和向量数据库默认保存在你的电脑本地。

---

### 2. 学术观点检索

例如输入：

> 城市经历可能改变流动人口评价自身社会地位时采用的参照标准。

系统会从本地论文中寻找最相关的证据，并返回论文名称、页码、相关原文及相关性信息。

---

### 3. 原文证据定位

检索结果会尽可能保留论文原文，而不仅仅生成 AI 摘要。

这样可以进一步回到 PDF 核查原始语境，降低学术写作中引用错误或 AI 虚构文献的风险。

---

### 4. PDF 原文跳转

点击论文名称或证据链接，可以直接在浏览器中打开对应 PDF。

系统会自动启动本地 PDF 浏览服务。

如果默认 PDF 端口已经被其他程序或另一个知识库占用，程序会自动寻找新的可用端口，无需手动修改。

---

### 5. 参考文献追溯

如果检索到的论文原文中出现类似：

> (Knight & Gunatilaka, 2010b; Wang, 2017)

系统会尝试：

1. 提取正文中的作者—年份引用；
2. 查找该论文的参考文献部分；
3. 匹配对应的完整参考文献条目；
4. 将成功匹配的参考文献显示在检索结果中。

---

## 二、系统要求

推荐使用：

- macOS
- Python 3
- 网络连接

首次运行时需要网络连接，因为程序可能需要下载 BGE-M3 模型，并需要调用 DeepSeek API。

---

## 三、Mac 安装方法

### 第一步：下载项目

在 GitHub 项目页面点击：

**Code → Download ZIP**

下载后解压到电脑中的任意位置，例如桌面。

---

### 第二步：运行安装程序

双击：

`install_mac.command`

安装程序会自动：

1. 检查 Python 3；
2. 创建 `.venv` 虚拟环境；
3. 安装项目依赖；
4. 创建 `papers` 文件夹；
5. 创建 `chroma_db` 文件夹；
6. 根据 `.env.example` 创建 `.env`。

安装时间取决于网络速度。

---

## 四、macOS 提示“无法打开”怎么办？

第一次运行 `.command` 文件时，macOS 可能提示无法验证开发者，或者阻止程序运行。

这是 macOS 的安全机制，并不一定代表程序本身存在错误。

可以按照以下方式操作：

1. 尝试双击 `install_mac.command`；
2. 如果系统阻止运行，打开：
   **系统设置 → 隐私与安全性**；
3. 找到刚刚被阻止的程序；
4. 点击 **“仍要打开”**；
5. 再次确认运行。

不建议通过关闭 macOS 整体安全机制的方式解决。

---

## 五、配置 DeepSeek API Key

安装完成后，需要配置自己的 DeepSeek API Key。

项目文件夹中会生成：

`.env`

由于 `.env` 是隐藏文件，如果 Finder 中看不到，可以按：

`Command + Shift + .`

显示隐藏文件。

打开 `.env`，找到：

```text
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

将：

```text
your_deepseek_api_key_here
```

替换成自己的 DeepSeek API Key。

请不要将自己的 API Key 上传到 GitHub，也不要分享给其他人。

---

## 六、启动程序

安装和 API Key 配置完成后，双击：

`启动学术文献助手.command`

程序会自动启动 Streamlit。

浏览器随后会打开本地学术文献助手页面。

如果浏览器没有自动打开，请查看终端窗口中显示的 Local URL。

---

## 七、第一次启动为什么比较慢？

第一次运行时，程序可能需要下载：

`BAAI/bge-m3`

这是用于文献向量化和语义检索的 embedding 模型。

模型文件较大，因此第一次运行可能需要等待一段时间。

下载完成后，后续一般不需要重复下载。

如果首次运行长时间停留在模型下载阶段，请先检查网络连接。

---

## 八、如何建立自己的论文知识库？

启动程序后，将自己的 PDF 论文上传到系统。

系统会：

1. 保存 PDF；
2. 提取论文文本；
3. 按页切分；
4. 生成向量；
5. 写入 ChromaDB。

完成后即可进行检索。

已经进入知识库的同名论文会尽量避免重复处理。

---

## 九、如何检索？

你可以直接输入：

> 教育扩张是否降低了教育的阶层区分作用？

或者：

> 流动经历会不会改变个体判断自身社会地位时采用的参照标准？

系统会优先从你的本地论文知识库中寻找相关证据。

如果知道具体论文，也可以进一步限定论文进行检索。

---

## 十、数据保存在哪里？

默认情况下：

- PDF：`papers/`
- 向量数据库：`chroma_db/`
- API Key：`.env`

这些内容不会通过本项目的 Git 配置上传到 GitHub。

因此，每个用户可以建立自己的私人论文知识库。

---

## 十一、关于隐私

需要特别说明：

PDF 文件、ChromaDB 数据库和 `.env` 默认保存在本地，并通过 `.gitignore` 排除，不会随代码自动上传到 GitHub。

但是，本项目并不是完全离线运行。

在使用 AI 分析功能时，系统会将**检索得到的相关文本片段和问题发送给 DeepSeek API**，用于生成证据分析结果。

因此，如果论文或材料包含敏感、保密或禁止发送给第三方服务的信息，请谨慎使用 API 分析功能。

---

## 十二、常见问题

### 1. 双击 `.command` 没反应

先检查是否已经运行：

`install_mac.command`

如果 macOS 阻止运行，请进入：

**系统设置 → 隐私与安全性 → 仍要打开**

---

### 2. 提示没有 `.venv`

说明安装程序还没有成功运行。

重新运行：

`install_mac.command`

---

### 3. 找不到 `.env`

Finder 中按：

`Command + Shift + .`

显示隐藏文件。

---

### 4. DeepSeek 报错

检查 `.env` 中是否正确填写：

```text
DEEPSEEK_API_KEY=你的APIKey
```

同时确认网络连接和 DeepSeek API 账户状态正常。

---

### 5. 第一次启动很慢

通常是因为正在下载 BGE-M3 模型。

首次下载完成后，后续启动通常会更快。

---

### 6. 点击 PDF 出现 404

最新版已经支持 PDF 浏览端口自动切换。

如果默认端口被其他知识库或程序占用，系统会自动寻找其他可用端口。

如果仍然出现问题，可以关闭当前程序后重新启动。

---

### 7. 新知识库没有论文会不会报错？

不会。

最新版支持空知识库启动。可以先打开程序，再逐步添加自己的 PDF。

## 十四、核心技术

本项目主要使用：

- Python
- Streamlit
- PyMuPDF
- ChromaDB
- Sentence Transformers
- BGE-M3
- DeepSeek API

基本流程：

`PDF → 文本提取 → 分页切块 → BGE-M3 Embedding → ChromaDB → 语义检索 → DeepSeek 证据分析 → PDF 原文定位`

## 十六、学术使用说明

本工具的目标是帮助研究者**寻找证据，而不是替代研究者判断证据**。

AI 返回的论文、页码、原文和参考文献信息仍建议回到原始 PDF 进行最终核查。

在正式论文、学位论文或研究报告中引用文献前，请以原始文献为准。
